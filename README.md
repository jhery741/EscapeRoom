
# EscapeRoom3D

## Descripción
Proyecto de videojuego 3D desarrollado en Unity.

## Integrantes
- Integrante A: Jhery Rodriguez Aguilar
- Integrante B: Jhamil Beymar Florez
- Integrante C: Stif Gerardo Lazo Barreto

## Tecnologías
- Unity
- C#
- Git y GitHub

## Desarrollo
El proyecto se desarrolla mediante ramas Feature
que se integran en Dev antes de llegar a main.

## Organización del trabajo
El equipo utiliza Git y GitHub para colaborar, controlar versiones y compartir los avances del proyecto.

## Objetivo del proyecto
Desarrollar un videojuego Escape Room en Unity donde el jugador resuelva acertijos e interactúe con objetos.
